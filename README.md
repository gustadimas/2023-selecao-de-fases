# Seleção de fases

Feito em ago/2023 a out/2023, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Sistema de seleção de fases que salvei como pacote. O `Fase_Management.cs` continua vivo entre as cenas (`DontDestroyOnLoad`), guarda o progresso e libera as fases; o `Level_Select.cs` e o `Level_Status.cs` cuidam do menu.

## Como abrir

Na época só exportei a pasta Assets num `.unitypackage`, então não tem ProjectSettings. Crie um projeto 2D vazio no Unity (nessa época eu usava a 2021.3) e importe `pacote-original/GuPacote.unitypackage` em Assets > Import Package > Custom Package.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
